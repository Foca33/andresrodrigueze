Drop the raw art here, then run `npm run assets:prepare`:

- hela-cover.(png|jpg)      front cover of HELA
- eric-wrap.(png|jpg)       full ERIC image (back + spine + front) — the RIGHT side is kept
  (or eric-cover.* if you already have the front cover alone)
- andres-portrait.(png|jpg) author portrait

Outputs go to public/assets/ and are picked up automatically.
